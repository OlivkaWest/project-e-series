# Готовые ролики

| Папка | Формат |
|---|---|
| `shorts/` | 1080×1920, мастер для YouTube Shorts / TikTok |
| `reels/` | 1080×1920, версия для Instagram Reels |
| `youtube/` | перемонтаж 3 серий в один ролик, 1080×1920 или 1920×1080 |
| `telegram/` | 1080×1920, ≤ 50 МБ |

Именование: `ep<NNN>-<площадка>-v<версия>.mp4`
