# VOICE — Аделаида

| Параметр | Значение |
|---|---|
| Тембр | детский, тёплый, обычный |
| Подача | **буднично, без страха** |
| Темп | обычный |
| Voice ID | `ELEVENLABS_VOICE_ADELAIDA`, фиксируется на сезон |
| Stability | 0,40 · Similarity 0,80 · Style 0,35 |
| Обработка (за дверью) | лёгкая реверберация комнаты + срез выше 5 кГц; разборчивость сохраняется |

## Главное правило

**Голос не должен звучать страшно.** Ни обработки «призрака», ни шёпота, ни эха,
ни понижения тона. Весь ужас сцены держится на том, что голос совершенно нормальный,
а ребёнка нет в кровати.

Если на приёмке голос звучит жутко — дубль бракуется.
