# Второстепенные персонажи

Каждому персонажу — своя папка по образцу `../main-character/`:

```
characters/supporting/<slug>/
├── CHARACTER.md
├── identity-lock.md
├── references/
├── expressions/
└── prompts/
```

Правило: персонаж, который появляется больше чем в одном эпизоде,
обязан иметь `identity-lock.md`. Разовые фоновые лица — не обязаны.
