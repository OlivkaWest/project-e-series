# Второстепенные персонажи

Каждый персонаж — своя папка по шаблону главного героя:

```
supporting/<slug>/
├── CHARACTER.md
├── identity-lock.md
├── references/
└── prompts/
```

Правило: персонаж получает `identity-lock.md`, если появляется **более чем в одном шоте**.
Одноразовые персонажи описываются прямо в `PROMPTS.md` эпизода.
