# Expressions — библиотека мимики

Один сид, одна внешность, разные состояния.

| Файл | Эмоция |
|---|---|
| `neutral.png` | нейтраль |
| `smile.png` | лёгкая улыбка |
| `anger.png` | гнев |
| `fear.png` | страх |
| `surprise.png` | удивление |
| `exhausted.png` | усталость |

Именование: `<эмоция>[-<интенсивность>].png`
