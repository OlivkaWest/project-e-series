# Expressions — библиотека мимики

Один файл = одна эмоция, сгенерированная с тем же identity-lock и seed.

| Файл | Эмоция | Где используется |
|------|--------|------------------|
| `neutral.png` | нейтраль | база |
| `surprise.png` | удивление | хук |
| `fear.png` | страх | эскалация |
| `anger.png` | злость | конфликт |
| `resolve.png` | решимость | поворот |

Промпт: базовый портрет + строка `EXPRESSION: ...`. Всё остальное не меняется.
