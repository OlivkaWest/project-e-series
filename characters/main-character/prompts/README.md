# Промпты главного героя

Готовые, проверенные блоки. Собираются как конструктор:

```
[identity-lock блок] + [expression] + [сцена: локация, действие, свет] + [style из VISUAL_LANGUAGE.md] + [negative]
```

## Файлы

| Файл | Назначение |
|------|-----------|
| `base-portrait.md` | базовый портрет для новых референсов |
| `base-fullbody.md` | ростовой план |
| `motion-base.md` | стартовый блок для video-моделей |

Правило: если промпт сработал — **сохранить его сюда с seed и версией модели**.
Промпт без seed считается неповторимым и в продакшн не идёт.
