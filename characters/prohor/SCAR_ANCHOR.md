# Шрам Прохора — точка постановки в композе

Шрам не генерируется. Он ставится в композе по этой спецификации, одинаково
во всех сериях сезона.

## Геометрия

| Параметр | Значение |
|---|---|
| Сторона | **правая** сторона лица героя (в кадре — слева, если он смотрит в камеру) |
| Привязка | верхний край правой брови, по надбровной дуге |
| Смещение вверх | 3 мм от линии роста волосков брови, в масштабе лица |
| Длина | 2 см в масштабе лица |
| Наклон | горизонталь, допуск ±5° |
| Ширина линии | волосяная, 1–2 px на мастере 1080×1920 |
| Цвет | на 8 % светлее окружающей кожи, без насыщенности |
| Края | мягкие, растушёвка 1 px; резкая линия читается как царапина |

## Порядок

1. Кадр принимается **без шрама**. В промпте лица шрам не упоминается: любое
   упоминание тянет модель рисовать лишние линии на лбу.
2. Лицо трекается, шрам ставится по привязке к брови, а не к кадру.
3. При повороте головы шрам укорачивается по косинусу угла и не меняет положения
   относительно брови.

## Проверка

- [ ] Сторона правая
- [ ] Привязан к брови, а не к лбу
- [ ] Один, не два
- [ ] Не светится и не темнеет при смене света в шоте
