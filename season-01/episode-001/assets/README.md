## Почему файлов может не быть в репозитории

Git LFS настроен (`.gitattributes`), но хост `lfs.github.com` закрыт политикой
исходящего трафика удалённой сессии — запушить бинарники оттуда нельзя.
Политика не обходится.

**Файлы кладёт владелец со своей машины:**

```bash
git lfs install
git add season-01/episode-001/assets/*.png
git commit -m "assets: эталонные кадры EP01"
git push
```
