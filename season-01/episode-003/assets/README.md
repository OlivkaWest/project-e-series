# Ассеты эпизода

```
assets/
├── keyframes/    # стартовые кадры для video-моделей (sh01.png, sh02.png…)
├── storyboard/   # превью раскадровки
├── voice/        # дорожки озвучки
├── music/        # музыка эпизода
├── sfx/          # звуки, специфичные для эпизода
└── subs/         # .srt
```

Общие для сериала ассеты (локации, реквизит, логотипы) живут в корневом `assets/`.
Бинарные файлы в git не коммитим — см. `.gitignore`.
