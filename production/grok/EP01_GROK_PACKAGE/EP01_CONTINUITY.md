# EP01 — континьюити между шотами

Каждый следующий кадр обязан согласоваться с предыдущим.

| Стык | Что переносится |
|---|---|
| SH001 → SH002 | вспучина светится; Прохор ещё не смотрел на панель |
| SH002 → SH003 | взгляд уже опущен влево-вниз; рука ещё не поднята |
| SH003 → SH004 | свечение погасло, створки открыты, свет вошёл слева |
| SH004 → SH005 | коридор пуст, полоса под дверью узкая |
| SH005 → SH006 | он у двери, **на ручке ничего не висит** |
| SH006 → SH007 | брелок замер; волос лежит у основания ручки |
| SH007 → SH008 | лицо впервые крупно; кожа обескровлена |
| SH008 → SH009 | решение принято; ладонь ещё цела |
| SH009 → SH010 | **ссадина на ЛЕВОЙ ладони** появилась, держится до EP03 |
| SH010 → SH011 | домофон горит зелёным; табличка 44 уже пуста |
| SH011 → SH012 | дверь приоткрыта ровно на 2 см и больше не открывается |
| SH012 → SH013 | щель та же; внутри 46-й всегда утро |
| SH013 → SH014 | **на ручке появилась резинка**, которой не было в SH006 |

## Неизменное на весь эпизод

* Куртка тёмно-синяя, нашивка только на левой груди и только пустая.
  Спина и плечи — ровная ткань без надписей.
* Ключи на правом бедре.
* Волосы растрёпаны после ночной смены — это состояние сцены, не идентичность.
* Кожа матовая, без бликов на лбу.
* Красный цвет допускается только с физическим источником в кадре.
* Дверь 46 без таблички с фамилией — её отсутствие часть загадки.
* Ребёнок существует силуэтом, затылком, рукой, пижамой, пустой кроватью
  и голосом. Лицо не генерируется никогда.

## Приём стыковки

Последний кадр принятого Grok-видео можно брать стартовым референсом следующего
шота там, где действие непрерывно: SH002 → SH003 и SH009 → SH010. Это сильнее
любого текстового описания.
