# Промо: «Квартира 46» собрана в терминале

Аватар HeyGen + вертикальный Reels. Хоррор идёт как B-roll.
Голос — Илья Алов. Одна мысль: **конвейер, а не генерации.**

---

## Основной скрипт · ~36 секунд

Копировать в HeyGen целиком. Абзацы = паузы.

```
Это не генерация. Это сериал.

Нейронка выдаёт один красивый кадр. На втором — другое лицо, другая дверь,
другой свет. Сериал так не соберёшь.

Поэтому я не генерил. Собрал конвейер прямо в терминале.
Пятнадцать агентов, у каждого своя работа.
Один держит сюжет. Второй принимает кадры.
Третий ловит несостыковки и может остановить всю смену.

Над ними библия. Четырнадцать файлов: как стоит камера, как падает свет,
как звучит дом. Спорить с ней агент не может.

Музыку не покупал — синтезировал кодом. Две версии выкинул, там был шум.
Третья — вот эта.

Серия одна. Вторую снимать или закрыть тему — сам ещё не решил.
Но досмотрите до конца. Там на дверной ручке резинка.
Если поняли зачем — вторая нужна.
```

**105 слов. При скорости 0,95 — примерно 36 секунд.**

## Что в кадре

| Сек | Голос | Картинка |
|---|---|---|
| 0–2 | «Это не генерация. Это сериал.» | **полный экран: SH001, панель лифта** |
| 2–8 | про другое лицо и другую дверь | два кадра рядом, дребезжащая склейка |
| 8–14 | пятнадцать агентов | скринкаст `ls .claude/agents/` |
| 14–20 | библия | дерево `bible/`, крупно |
| 20–27 | музыка | `score_ep01.py`, скролл кода |
| 27–32 | **аватар молчит** | **SH014, резинка на ручке, со звуком** |
| 32–36 | «вторую снимать — не решил» | аватар, крупно |

**Не сокращать блок 27–32.** Аватар там молчит, играет только финал со своим
ударом. Слова про музыку без этого — просто слова.

## Настройки HeyGen

Формат 9:16, 1080×1920. Скорость речи 0,95 — быстрее цифры сливаются.
Тон ровный, без нажима: материал сам мрачный. Субтитры обязательно.
«Claude Code» писать транслитом — **Клод Код**, иначе аватар скажет «Клауд».
