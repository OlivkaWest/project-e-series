# Промо-ролик: «Собрано в Claude Code»

Материал для аватара HeyGen + вертикальный Reels. Сам хоррор-ролик идёт как B-roll,
аватар — как ведущий.

Все числа проверены по репозиторию. Ничего не округлено вверх.

---

## 1. Скрипт для HeyGen · 50 секунд · основной

Копировать в HeyGen целиком, без заголовков. Точки и абзацы держат паузы.

```
Здесь нет ни камеры, ни актёров, ни Premiere. Только терминал.

Это вертикальный хоррор-сериал. Первая серия — «Квартира сорок шесть».
Сценарий, кадры, видео, монтаж и звук собраны в Claude Code.

В проекте пятнадцать агентов. Шоураннер держит арку сезона.
Режиссёр по хоррору принимает кадры и имеет право их отклонить.
Супервайзер непрерывности имеет право остановить производство.
Промпт-директор пишет промпты отдельно под каждую модель.

Над всеми ними — библия из четырнадцати файлов.
Язык камеры. Язык света. Звук. Символы. Правила имён.
Агент не спорит с библией. Противоречие с ней — это ошибка, а не творческое решение.

Музыку никто не лицензировал. Она синтезирована из трёхсот тридцати трёх строк кода.
Партитуру переписывали трижды. Первая версия ушла в брак:
спектральная плоскостность ноль целых двадцать один — это шум, а не музыка.

И проверка, которую человек бы пропустил.
Пульс жил на тридцати шести герцах. Динамик телефона такое не воспроизводит.
Ритм перенесли в слышимую полосу и замерили — плюс семь децибел над фоном.

Это не готовый продукт. Это репозиторий.
Промпты, агенты, журнал ошибок и всё, что не получилось с первого раза.
```

**Хронометраж:** 148 слов. При скорости речи 0,95 — около 52 секунд.

## 4. Раскладка B-roll

Аватар не должен занимать весь экран. Схема — аватар в нижней трети,
хоррор-материал сверху, либо полноэкранные врезки.

| Время | Что на экране | Что говорит аватар |
|---|---|---|
| 0–3 | **полный экран: SH001 панель лифта** | «Здесь нет ни камеры…» |
| 3–10 | аватар + SH002 зеркало | «Это вертикальный хоррор-сериал…» |
| 10–18 | скринкаст: `ls .claude/agents/` | «В проекте пятнадцать агентов…» |
| 18–26 | скринкаст: дерево `bible/` | «Над всеми ними — библия…» |
| 26–34 | скринкаст: `score_ep01.py` | «Музыку никто не лицензировал…» |
| 34–42 | график уровня из терминала | «Первая версия ушла в брак…» |
| 42–48 | **полный экран: SH014 резинка, со звуком** | пауза, говорит только музыка |
| 48–52 | аватар | «Это не готовый продукт. Это репозиторий.» |

**Ключевое:** на 42–48 аватар молчит. Финальный кадр серии должен прозвучать
со своим CLIFFHANGER, иначе весь аргумент про музыку не подтверждается на слух.

## 5. Настройки HeyGen

| Параметр | Значение | Почему |
|---|---|---|
| Формат | 9:16, 1080×1920 | как мастер сериала |
| Скорость речи | 0,95 | быстрее — цифры сливаются |
| Пауза после абзаца | 0,4 с | абзацы в скрипте расставлены под паузы |
| Тон | ровный, без нажима | материал сам мрачный, подача не должна давить |
| Субтитры | обязательно | смотрят без звука |

**Произношение.** «Claude Code» — «Клод Код». Если аватар произносит как «Клауд»,
писать в скрипте транслитом: `Клод Код`.

## 7. Что говорить нельзя

Правило 2 из `CLAUDE.md` — ничего не выдумывать поверх данных. Это относится
и к рекламе.

| Нельзя | Почему | Как правильно |
|---|---|---|
| «готовая серия» | смонтированы 10 шотов из 14, ролик идёт 18 секунд | «рабочая сборка», «серия в производстве» |
| «сделано за один вечер» | нет замера времени | не называть срок вообще |
| «полностью без человека» | все приёмки делает владелец | «собрано в Claude Code» |
| «озвучено ИИ» | голоса в ролике нет | не упоминать голос |
| называть чужие сериалы | правило 4, своя IP | описывать приёмом, а не сравнением |

**Про ссылку.** В скрипте нет фразы «ссылка в описании»: репозиторий приватный.
Если открывать его — добавить финальную строку. Если нет — оставить как есть,
последняя фраза работает и без ссылки.
