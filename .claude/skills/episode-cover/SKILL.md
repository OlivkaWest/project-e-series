# EPISODE COVER

## Правило обложки

```
1 главный хук
1 визуальный конфликт
1 понятный термин
```

Обложка **не пересказывает серию**. Она задаёт один вопрос, ответ на который внутри.

## Что на обложке

| Элемент | Правило |
|---|---|
| Кадр | один предмет крупно, один источник света, чёрный фон — либо кадр-постер серии |
| Лицо | не чаще одной обложки из трёх |
| Текст | Oswald Light 300, капслок, трекинг +18 %, **не более трёх слов**, нижняя треть |
| Красный | только если это физический объект в кадре |
| Логотип сериала | на обложке отсутствует |

## Правило текста

Текст обложки — это **утверждение, которое невозможно принять спокойно**, а не описание.

```
ПЛОХО:  «Серия 1. Прохор находит дверь»
ХОРОШО: «В ДОМЕ 9 ЭТАЖЕЙ»
```

Второе работает, потому что зритель видит на кадре цифру 46 и не может свести одно с другим.

## Заголовок ролика

Формула: **невозможный факт + личная ставка + номер серии**.

```
В нашем доме девять этажей. Ночью в лифте загорелась кнопка 46 | Серия 1
Я произнёс её имя вслух. Утром в списке появилась Серафима | Серия 3
У Лукерьи никогда не было брата. Я видел Феофана вчера | Серия 5
```

Редкое имя в заголовке работает как крючок: его запоминают и по нему ищут.

## Описание

Три строки: что произошло, чем это грозит, когда следующая серия.
Ни одного спойлера финала. Ни одного «подпишись».

## Проверка

- [ ] Обложка читается на экране телефона размером с ноготь?
- [ ] Один вопрос, а не три?
- [ ] Текст ≤ 3 слов?
- [ ] Красное имеет источник?
- [ ] Заголовок содержит невозможный факт в первых пяти словах?
