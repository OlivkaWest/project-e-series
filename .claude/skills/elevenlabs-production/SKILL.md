# ELEVENLABS PRODUCTION

**Статус:** SDK установлен (`elevenlabs==2.18.0`), ключ отсутствует — `NEEDS_KEY`.
Адаптер: `integrations/elevenlabs/`.

## Что нужно от владельца

```bash
# в .env, не в репозиторий
ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_PROHOR=...
ELEVENLABS_VOICE_SERAFIMA=...
ELEVENLABS_VOICE_ADELAIDA=...
ELEVENLABS_VOICE_HOUSE=...
```

## Возможности, которые нам нужны

| Возможность | Зачем в сериале |
|---|---|
| Text-to-speech | реплики персонажей |
| Voice design / cloning | постоянные голоса на весь сезон |
| **Timestamps** | словные таймкоды → субтитры без отдельной транскрипции |
| Sound effects | точечные звуки, которых нет в библиотеке |
| Pronunciation control | термины мира: «со́рок шеста́я», «ноль со́рок шесть» |
| Reusable voice IDs | голос персонажа не меняется между сериями |

## Правило проекта

**Voice ID фиксируется один раз** на CHECKPOINT 5 и не меняется до конца сезона.
Смена голоса — такое же нарушение непрерывности, как смена лица.

## Настройки по персонажам

| Персонаж | Stability | Similarity | Style | Характер подачи |
|---|---:|---:|---:|---|
| Серафима | 0,55 | 0,85 | 0,20 | сообщает факт, не пугает |
| Прохор | 0,45 | 0,80 | 0,30 | на выдохе, почти шёпотом |
| Аделаида | 0,40 | 0,80 | 0,35 | буднично, **не «страшно»** |
| Дом | 0,60 | 0,85 | 0,15 | ровно, без эмоции |

Дом дополнительно обрабатывается: полоса 300–3400 Гц, лёгкая компрессия, без реверберации.

## Нормы

Речь −16 LUFS, пики ≤ −1 dBTP. Реплика ≤ 8 слов. Один дубль — одна сцена.

## Резервный путь

Если ключа нет, а озвучка нужна для теста — доступен `seed_audio` (ByteDance Seed Audio 1.0)
через подключённый канал. Это черновик, не финал: голоса персонажей делаются в ElevenLabs.
