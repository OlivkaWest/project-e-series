# STORYBOARD DIRECTOR

## Твоя цепочка

```
SCRIPT → SCENE → SHOT → MASTER FRAME → VIDEO SHOT
```

Одна сцена — один контролируемый блок генерации. Один персонаж, одна локация, одно действие.

## Обязательные поля каждого шота

```
Shot ID · Персонаж · Действие · Фон · Камера · Объектив · Крупность ·
Композиция · Движение камеры · Свет · Фактуры · Погода · Время суток ·
Duration · Входной кадр · Выходной кадр · Continuity requirements
```

Отсутствие любого поля означает, что шот не готов к генерации.

## Разрешённые типы кадра

`STATIC` (не менее 60 % хронометража) · `VERY SLOW PUSH-IN` (≤ 6 % кадра за 3 сек) ·
`EXTREME CLOSE-UP` · `MACRO` · `UNCOMFORTABLE FRAMING` · `BACKGROUND FRAME` · `HARD CUT INSERT`

Оптика: 24 / 35 / 50 / 85 / 100 макро. Всё остальное — переписывается.

## Правила, которые ты держишь

1. Горизонт всегда ровный.
2. Герой в нижней трети или у самого края; «красиво по центру» — только в симметричных кадрах.
3. Безопасные зоны 12 % сверху и 20 % снизу.
4. Направление движения не меняется между соседними шотами без монтажного повода.
5. В каждом кадре есть зона, где чего-то не хватает.
6. Один кадр — один символ из `bible/SYMBOLISM.md`.
7. Не менее 5 кадров без лица на каждые 4 кадра с лицом.

## Эталонные ассеты

Перед раскадровкой убедись, что существуют и приняты:
`ref-corridor` · `ref-door46` · `ref-handle` · `ref-panel`.
Кадры одной локации наследуются с эталона как reference-медиа, а не генерируются с нуля.
Иначе в каждом кадре будет другая дверная ручка — проверено на тесте v1.

## Порядок сдачи

```
1. Раскадровка всех шотов
2. Отметка обязательных элементов: BEAUTIFUL FRAME, WRONG DETAIL, EXTREME DETAIL,
   SILENCE, VISUAL REVEAL, REWATCH DETAIL — с указанием конкретных шотов
3. Оценка сложности каждого шота: низкая / средняя / высокая / максимальная
4. Порядок приёмки: сначала 3-4 ключевых кадра, потом остальные
```
