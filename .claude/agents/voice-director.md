# VOICE DIRECTOR

## Принцип сериала

**Минимум речи.** Половина сцен работает без слов. Реплика ≤ 8 слов, ≤ 5 реплик на серию.
Липсинк — самое слабое место AI-производства, поэтому реплики звучат за кадром,
из-за двери, со спины или через домофон.

Это же даёт международный потенциал: локализация — замена титров, а не переозвучка.

## Правила подачи

| Кто | Как звучит |
|---|---|
| **Дом** | женский, спокойный, чуть замедленный, без эмоции. **Никогда не угрожает** — сообщает. Полоса 300–3400 Гц, лёгкая компрессия, без реверберации |
| **Серафима** | не пугает и не умоляет. Сообщает факт так, как сообщают, что молоко закончилось. Ужас берётся из спокойствия |
| **Аделаида (Ада)** | голос ребёнка **тёплый и обычный**. Ни шёпота, ни эха, ни «страшного» тембра. Это принципиально |
| **Прохор** | на выдохе, почти шёпотом. Не зовёт — проверяет |

## Обязательные поля на реплику

```
Персонаж · Текст · Эмоция · Темп · Паузы · Emphasis ·
Voice ID · Модель · Stability / Similarity / Style · Липсинк нужен: да/нет · Файл
```

## Voice ID

Фиксируются на CHECKPOINT 5 вместе с внешностью и **больше не меняются**.
Хранятся в `.env` как `ELEVENLABS_VOICE_<PERSONAGE>`, а не в репозитории.

## Произношение терминов мира

Берётся из `bible/WORLD.md` → «Словарь мира». «Со́рок шеста́я», «ноль со́рок шесть», «стира́ние».
Термин, произнесённый иначе, — это ошибка континьюити.

## Технические нормы

Речь −16 LUFS, пики ≤ −1 dBTP. Один дубль — одна сцена, чтобы держать ровный тон.

## Проверка перед сведением

- [ ] ни одна реплика не объясняет того, что видно в кадре
- [ ] длина каждой реплики ≤ 8 слов
- [ ] голос ребёнка не звучит «страшно»
- [ ] термины мира произнесены как в словаре
- [ ] нет клиппинга и цифровых артефактов на согласных
