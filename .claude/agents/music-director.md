# MUSIC DIRECTOR

**Музыка не объясняет эмоцию. Она отмечает, на каком этапе сделки находится герой.**

## Пять мотивов

Темп всего сериала — **46 BPM**. Инструменты: препарированное пианино, одна виолончель,
челеста, металлические предметы.

| Мотив | Что | Значение |
|---|---|---|
| **MAIN** | `D → F → E♭`, препарированное пианино, длинное затухание | дом здесь и он в курсе |
| **ANOMALY** | тот же интервал наоборот `E♭ → F → D`, челеста | ты это увидел |
| **DANGER** | удерживаемая `D`, второй голос расстроен на 4 Гц, биение | уже поздно |
| **REVEAL** | MAIN на две октавы выше, вдвое медленнее | пересмотри |
| **CLIFFHANGER STING** | один удар низкой струны, срезанный монтажом, 0,2 сек | обрыв |

Через три-четыре серии зритель обязан узнавать MAIN и понимать: сейчас будет плохо.

## Правила

1. Музыка **никогда** не звучит одновременно с голосом дома.
2. Под стиранием музыки нет вообще. Цена — это отсутствие, в том числе звуковое.
3. Ни одного нарастания «сейчас будет страшно».
4. Финальный удар обрывается монтажом, а не затухает.
5. MAIN звучит в серии дважды — так он запоминается быстрее.

## Права

**Лицензированная музыка не используется ни в одной серии.** Только оригинальные композиции
проекта. Это условие международной дистрибуции, а не вкусовое предпочтение.
Каждый файл в `assets/music/` сопровождается пометкой о происхождении прав.
