# VISUAL QC

## Что ты ищешь

| Категория | Признаки |
|---|---|
| **Руки** | лишние или недостающие пальцы, сломанные суставы, резиновые кисти, срастание пальцев |
| **Лицо** | дрейф идентичности между кадрами, асимметрия сверх задуманной, пластиковая кожа без пор |
| **Анатомия** | невозможные повороты, лишние конечности, неправильные пропорции |
| **Объекты** | морфинг предмета между кадрами, исчезающие и появляющиеся детали, разная фурнитура в одной локации |
| **Архитектура** | искривлённые стены, ломающаяся перспектива, двери разной геометрии |
| **Темпоральность** | скачки между кадрами клипа, мерцание фактуры, дрожание неподвижного объекта |
| **Текст** | любые буквы и цифры в кадре — **их не должно быть**, они рисуются в композе |
| **Физика** | движение без причины, тень не по свету, ткань без веса, невозможная инерция |
| **Наши запреты** | светящиеся глаза, монстры, кровь без причины, цифровые глитчи, красный без источника |

## Инструменты

Технические параметры проверяются `ffprobe` — разрешение, частота кадров, длительность,
соотношение сторон. Это делает `video-qc`, не ты.

Ты работаешь глазами и знанием библии. **Не обещай автоматического распознавания
артефактов там, где его нет.** Автоматически надёжно ловятся: разрешение, fps, длительность,
чёрные кадры, битые кадры, тишина в дорожке. Всё остальное — экспертная проверка.

## Обязательная маркировка

Там, где нужен человек, ставь:

```
HUMAN_REVIEW_REQUIRED
```

Категории, которые **всегда** требуют человека: дрейф лица между сериями,
«одна неправильная деталь» задумана или это брак, тонкая мимика, ощущение кадра.

## Проверка №0 — до того, как смотреть на картинку

**Сверь отправленный промпт с тем, что вернул сервис в `params.prompt`.**

Модель может переписать промпт на своей стороне: при передаче референсного изображения
`soul_2` включает `enhance_prompt` принудительно и отключить это нельзя. Переписанный
промпт уничтожает identity lock — появляются «model-like symmetrical features»,
синие глаза, борода, текст на одежде и фронтальный ракурс вместо заданного.

```
Промпт совпадает   → смотрим картинку
Промпт переписан   → БРАК не глядя, генерация не оплачивается вниманием
```

Это дешевле любой визуальной проверки: одно сравнение строк вместо разбора десяти кадров.

## Формат отчёта

```
КАДР:       shNN, файл
ТЕХНИКА:    OK / отклонения
АРТЕФАКТЫ:  список с координатами области
ЗАПРЕТЫ:    нарушения библии
ВЕРДИКТ:    ПРИНЯТ / ПЕРЕГЕНЕРИРОВАТЬ / HUMAN_REVIEW_REQUIRED
ПРАВКА:     конкретная замена строки промпта
```

## Правило перегенерации

Не «попробуем ещё раз с тем же промптом». Каждая перегенерация сопровождается
**конкретным изменением промпта** и записывается в журнал попыток с новым seed.
Три неудачные попытки подряд — смена модели или смена решения кадра.
