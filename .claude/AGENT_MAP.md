# AGENT MAP — кто за что отвечает

Пятнадцать агентов, каждый с узкой функцией. Ни один не дублирует другого.

## Таблица

| Агент | Функция | Вызывается | Может блокировать |
|---|---|---|---|
| `showrunner` | библия, арка, сквозная тайна, развитие героев | решение затрагивает > 1 серии | да |
| `viral-scriptwriter` | покадровый сценарий с удержанием | после утверждения хода серии | нет |
| `horror-director` | визуальная эстетика, перевод референса в параметры | перед промптом, при приёмке кадра | **да** |
| `character-director` | консистентность лиц, гардероб, identity lock | новый персонаж, кадр с лицом | **да** |
| `prompt-director` | промпты под конкретную модель | перед любой генерацией | нет |
| `storyboard-director` | сцены → шоты → кадры | после утверждения сценария | нет |
| `video-director` | промпты видеогенерации, выбор движка | после приёмки мастер-кадров | нет |
| `voice-director` | голоса, подача, произношение | работа с VOICE.md | нет |
| `sound-designer` | слои, cue sheet, тишина | работа с SOUND.md | нет |
| `music-director` | пять мотивов и их применение | работа с MUSIC.md | нет |
| `editor` | ритм, паузы, стыки, тайминг раскрытия | после приёмки клипов и звука | нет |
| `continuity-supervisor` | непрерывность между сериями | перед генерацией и после приёмки | **да** |
| `visual-qc` | артефакты AI, дрейф, запреты библии | после каждой генерации | **да** |
| `video-qc` | технические параметры файла | перед экспортом | **да** |
| `retention-editor` | удержание глазами зрителя Shorts | перед финальным экспортом | **да** |

## Кто чего НЕ делает

* `showrunner` не пишет диалоги.
* `viral-scriptwriter` не придумывает сюжет и не меняет канон.
* `horror-director` не пишет промпты — он их проверяет.
* `visual-qc` не проверяет технические параметры — это `video-qc`.
* `editor` не решает, работает ли серия — это `retention-editor`.
* Ни один агент не отменяет запись в `bible/CONTINUITY.md`, кроме `continuity-supervisor`.
