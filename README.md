# project-e-series

AI-native продакшн-система вертикального сериала: исследование → механика → концепция →
сезон → сценарии → персонажи → storyboard → генерация → звук → монтаж → публикация.

## Статус

**PHASE 1 — MANUS INTELLIGENCE: завершена.**
Формат выбран, концепция предложена, ждём подтверждения (`CHECKPOINT 1`).
Библия, сезон и сценарии не пишутся до утверждения.

Читать в этом порядке:

1. `research/manus-analysis/SOURCE_INDEX.md` — что за источники и чему можно верить
2. `research/manus-analysis/MANUS_SUMMARY.md` — извлечённые данные и пересчёт
3. `research/manus-analysis/VIRAL_PATTERNS.md` — механика внимания
4. `research/manus-analysis/FORMAT_RANKING.md` — 10 форматов, единая шкала
5. `research/manus-analysis/FINAL_DECISION.md` — **решение и концепция**

## Структура

```
bible/                 библия сериала (шаблоны, заполняются после утверждения)
characters/            персонажи: карточка, identity lock, референсы, промпты
season-01/             арка сезона и эпизоды
prompts/               форматы промптов по инструментам
assets/                локации, пропсы, музыка, звук, логотипы
pipeline/              скрипты производства
research/              исследование и его разбор
output/                готовые ролики по площадкам
```
