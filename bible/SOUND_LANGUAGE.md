# SOUND LANGUAGE — «Квартира 46»

Звук в этом сериале — **конструкция из материалов**, а не «страшная музыка».
Половина сцен работает без слов, поэтому звук несёт половину смысла.

---

## 1. Девять слоёв

Любая сцена собирается из этих слоёв. Больше четырёх одновременно не звучит никогда.

| # | Слой | Что это у нас |
|---:|---|---|
| 1 | **industrial ambience** | гул лифтовой шахты, вентиляция, дальний лифт соседнего подъезда |
| 2 | **low frequency drone** | 46 Гц, почти неслышный, включается, когда дом «внимателен» |
| 3 | **metal friction** | трос лифта, петли, ключ в личинке, кольцо брелока о ручку |
| 4 | **distant breathing** | чужое дыхание за стеной или за дверью, никогда близко к микрофону |
| 5 | **mechanical clicks** | реле, выключатель, стартер люминесцентной лампы, домофон |
| 6 | **fabric movement** | куртка, пижама, кардиган, ковровая дорожка под ногой |
| 7 | **reversed textures** | реверс обычного звука комнаты, длиной 0,5–1,5 сек, под моменты «неправильного» |
| 8 | **medical / institutional** | гудение трубки, тонкий писк, стук стекла о металл, скрип каталки в глубине |
| 9 | **single distorted motif** | один музыкальный мотив, пропущенный через плёнку и металл |

Редкие вставки, не чаще одного раза за серию каждая: детский голос, шёпот,
одна нота фортепиано, стук, щелчок, вдох.

---

## 2. Правила

1. **Никаких скримеров.** Ни одного звукового удара на испуг за весь сезон.
2. **Стирание не озвучивается.** Цена всегда происходит в звуковой пустоте.
3. Музыка и голос дома не звучат одновременно.
4. Тишина — раз в серию, 1–2 секунды, полная, все слои сняты.
5. Реверс используется только там, где в кадре есть «неправильная деталь».
6. Ни одного звука без физического источника, кроме дрона 46 Гц.
7. Финальный кадр обрывается монтажным cut'ом, без затухания хвоста.

---

## 3. Музыкальные мотивы

Темп всего сериала — **46 BPM**. Инструменты: препарированное пианино (между струнами
проложен войлок), одна виолончель, челеста, металлические предметы.

### MAIN MOTIF — «дом»
```
Три ноты, нисходящие:   D → F → E♭
Инструмент:             препарированное пианино, длинное затухание
Где:                    заставка, начало серии, титул
Смысл:                  дом здесь и он в курсе
```

### ANOMALY MOTIF — «что-то не так»
```
Тот же интервал, обратный порядок:  E♭ → F → D
Инструмент:                          челеста, верхняя октава
Где:                                 в момент, когда зритель замечает неправильную деталь
Смысл:                               ты это увидел
```

### DANGER MOTIF — «сейчас спишут цену»
```
Одна нота D, удерживаемая; поверх второй голос расстроен на 4 Гц — возникает биение
Инструмент:                          виолончель + дрон
Где:                                 перед стиранием
Смысл:                               уже поздно
```

### REVEAL MOTIF — «смысл изменился»
```
MAIN MOTIF на две октавы выше, в два раза медленнее
Инструмент:                          челеста, почти на пороге слышимости
Где:                                 финальный кадр серии с раскрытием
Смысл:                               пересмотри
```

### CLIFFHANGER STING
```
Один удар по низкой струне виолончели, срезанный монтажом до затухания
Длительность:                        0,2 сек
Где:                                 последний кадр
Смысл:                               обрыв
```

Через три-четыре серии зритель обязан узнавать MAIN MOTIF и понимать: сейчас будет плохо.

## 5. Голос дома

Женский, спокойный, чуть замедленный, без эмоции. Обработка: полоса 300–3400 Гц,
лёгкая компрессия, без реверберации. Дом **никогда не угрожает** — он сообщает.
