# STORY RULES — Story Engine «Квартиры 46»

Алгоритм, по которому пишутся десятки серий без ощущения повтора.
Ядро не меняется; меняется только **кто платит и чем**.

---

## 1. Двигатель серии

```
НОРМА          обычный быт подъезда, узнаётся за 1 секунду
   ↓
АНОМАЛИЯ       один невозможный факт в кадре, без титра и объяснения
   ↓
ОБНАРУЖЕНИЕ    герой понимает правило раньше окружения; зритель — раньше героя
   ↓
РЕШЕНИЕ        герой берёт / нажимает / выносит / обещает
   ↓
ЦЕНА           один физический след человека исчезает ПРЯМО В КАДРЕ
   ↓
ЭСКАЛАЦИЯ      цена оказывается ближе, чем он рассчитывал
   ↓
ВОПРОС         один предметный кадр, читаемый без звука
```

## 2. Сетка по секундам (серия 30–35 сек)

| Секунды | Такт | Что обязано быть в кадре | Проверка |
|---|---|---|---|
| **0:00–0:02** | АНОМАЛИЯ | Невозможный объект крупно. Ни логотипа, ни титра, ни номера серии | Понятно без звука? |
| 0:02–0:05 | НОРМА | Кто это и где мы. Одно лицо, одна локация | Зритель называет место? |
| 0:05–0:10 | ОБНАРУЖЕНИЕ | Герой видит то, чего не видят другие | Ставка формулируется одним предложением? |
| 0:10–0:16 | РЕШЕНИЕ | Ошибка совершена: рука взяла, палец нажал | Ошибка понятна без реплики? |
| 0:16–0:22 | ЦЕНА | Стирание в кадре, ≤ 2 секунды, без объяснения | Видно ли, что именно исчезло? |
| 0:22–0:30 | ЭСКАЛАЦИЯ | Цена касается близкого человека | Стало ли лично? |
| 0:30–0:33 | ТИШИНА | 0,5–1 секунда без музыки | Есть ли пауза перед ударом? |
| 0:33–0:35 | ВОПРОС | Финальный кадр, один незакрытый факт | Вопрос один, а не два? |

## 3. Первые две секунды: список разрешённых хуков

Разрешено только это. Всё остальное — переписывается.

1. Кнопка 46 проступает на панели изнутри.
2. На списке жильцов рядом с фамилией проступает `00:46`.
3. Из-под двери, которой нет, идёт тёплый свет.
4. Домофон загорается сам и называет имя.
5. Предмет стёртого человека лежит там, где его не может быть.
6. Фамилия сходит с почтового ящика, буквы гаснут.
7. На фотографии рядом с человеком — пустое место, которого вчера не было.
8. Цифра этажа на табло: после «9» загорается «46».

**Запрещено в первых двух секундах:** логотип, название сериала, номер серии, заставка,
установочный план дома, лицо героя без действия, любой титр длиннее 4 слов.

## 4. Правило видимой цены

В каждой серии ровно **одно стирание**, и оно обязано быть:

* **физическим** — исчезает предмет, буква, лицо на фото, вещь на крючке;
* **в кадре** — не за кадром, не в реплике;
* **коротким** — ≤ 2 секунды;
* **необъяснённым** — никто не говорит «смотри, оно исчезает»;
* **часто незамеченным героем** — это и есть источник тревоги: зритель знает больше.

## 5. Правило «зритель знает больше героя»

Минимум один раз за серию зритель видит то, чего не видит Кирилл: стирание за его спиной,
строку в списке, отражение, движение в глубине коридора.
Это главный механизм удержания: зритель не разгадывает загадку, он **предупреждает героя**.

## 6. Диалог

| Правило | Норма |
|---|---|
| Длина реплики | ≤ 8 слов |
| Реплик на серию | ≤ 5 |
| Объяснение видимого | запрещено |
| Приветствия, прощания, «что происходит?» | запрещены |
| Голос дома | ≤ 2 реплики за серию, спокойно, без угрозы |
| Реплика ребёнка | не более 4 слов, всегда бытовая |

## 7. Текст на экране

* ≤ 12 слов, ≤ 2 строк, ≤ 42 знака в строке.
* Разрешён только как часть мира: список жильцов, экран телефона, табло, надпись на двери.
* Титры-пояснения от автора запрещены.

## 8. Финал серии

Финальный кадр строится по формуле:

> **предмет + отсутствие** = вопрос

Примеры: рука на ручке двери + пустая кровать на экране телефона; список + новая строка;
фотография + расширившееся пустое место.

Следующая серия **обязана** ответить на этот вопрос в первые две секунды и создать новый долг.

## 9. Как рождается новая серия (шаблон для 30–50 эпизодов)

1. Выбрать строку из списка жильцов — кто следующий.
2. Ответить: **что герой хочет вынести** из завтра в этой серии.
3. Ответить: **кем он за это платит** и знает ли он об этом.
4. Найти один физический предмет, через который цена станет видна.
5. Сформулировать один вопрос финального кадра.
6. Проверить: что заставляет смотреть следующие 3 секунды — в каждой точке серии.

Если на шаге 6 хоть в одном месте нет ответа — сцена переписывается.

## 10. Арка сезона по актам

| Акт | Серии | Кто платит | Что меняется в герое |
|---|---|---|---|
| **1. ДВЕРЬ** | 01–03 | посторонние | из «мне никто не верит» в «я знаю правило» |
| **2. ЦЕНА** | 04–06 | знакомые и соседи | из «я осторожен» в «я считаю чужих допустимой платой» |
| **3. ДОЛГ** | 07–09 | его близкие | из «я плачу» в «я сам оплачен» |
| **4. ЖИЛЕЦ** | 10–12 | он сам | из «вернуть мать» в «выбрать, кем остаться» |
