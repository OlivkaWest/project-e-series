# Story Rules — драматургические правила

Проверочный лист. Эпизод не идёт в продакшн, пока не проходит все пункты.

## 1. Правила хука (первые 3 секунды)

- [ ] В первом кадре есть движение или аномалия.
- [ ] Зритель может сформулировать вопрос к 3-й секунде.
- [ ] Нет логотипа, титров, «привет, друзья» в начале.
- [ ] Первая реплика — не приветствие, а действие.

## 2. Правила сцены

- [ ] У сцены одна функция. Две функции = две сцены.
- [ ] Сцена начинается максимально поздно и кончается максимально рано.
- [ ] В конце сцены расстановка сил изменилась.
- [ ] Ни одна сцена не объясняет то, что уже показано.

## 3. Правила диалога

- [ ] Реплика ≤ 12 слов, если это не осознанный монолог.
- [ ] Персонажи не произносят вслух свои мотивы.
- [ ] Никакой экспозиции через «как ты помнишь, …».
- [ ] Каждый персонаж узнаваем по репликам без подписи.

## 4. Правила эскалации

- [ ] Каждая следующая проблема дороже предыдущей.
- [ ] Герой действует, а не реагирует, минимум один раз за эпизод.
- [ ] Решение героя создаёт новую проблему.

## 5. Правила финала эпизода

- [ ] Поворот меняет смысл уже увиденного, а не добавляет новое.
- [ ] Последний кадр — вопрос, не точка.
- [ ] Крючок обещает конкретную сцену, а не «будет интересно».

## 6. Запреты

- Сон / «это был не он» / внезапный спасатель из ниоткуда.
- Разрешение конфликта за счёт способности, о которой не сказали заранее.
- Закадровый голос, объясняющий эмоцию, которая видна на лице.
- Клиффхэнгер, который не отрабатывается в следующем эпизоде.

## 7. Сеттапы и выплаты

Каждый setup обязан выплатиться в течение 3 эпизодов. Журнал — в
[`CONTINUITY.md`](CONTINUITY.md), раздел «Setup / Payoff».
