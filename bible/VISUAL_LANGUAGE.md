# VISUAL LANGUAGE — «Квартира 46»

Источник правды для всех промптов. Любой кадр наследует блоки отсюда.

---

## 1. Общее ощущение

**Холодный документальный реализм подъезда с одним тёплым источником света, которого там быть не должно.**

Стиль — стилизованный кинематографичный реализм (2.5D-realism), а не попытка каждую секунду
имитировать дорогую съёмку. Стилизация делает консистентность генерации частью языка, а не браком.

## 2. Палитра

| Роль | Название | HEX | Где применяется |
|---|---|---|---|
| Основной холод | подъездный синий | `#0E1621` | коридор, лестница, ночь |
| Металл | лифтовый графит | `#1C2B3A` | кабина, панель, двери |
| **Акцент тепла** | янтарь сорок шестой | `#E3A857` | свет из-под двери, кухня «завтра» |
| **Акцент угрозы** | сигнал 46 | `#C8332B` | кнопка 46, табло, время `00:46` |
| Свет | бумага и дверь | `#F2EDE4` | белая дверь, список жильцов, титры |
| Кожа | нейтральный тёплый | — | лица держим в тёплой зоне даже в холодном кадре |

Правило: **в кадре не больше двух акцентов одновременно.** Красный и янтарь вместе — только
на пороге двери.

## 3. Свет

* Один мотивированный источник в кадре. Второй — только контровой.
* Коридор: одна лампа, мигает один раз каждые 4 секунды (ритм-маркер сериала).
* Лифт: верхний холодный, лицо снизу недосвечено.
* Дверь 46: тёплая щель снизу, ширина 3–5 см, свет «дышит».
* Кухня «завтра»: мягкий янтарный, окно за спиной, утро.
* Квартира Ани: ночник у кровати Лены, всё остальное — темнота.
* Контраст: высокий в подъезде, мягкий за дверью.

## 4. Оптика и камера

| Параметр | Значение |
|---|---|
| Фокусные | 35 мм — подъезд и коридор; 50 мм — сцены с людьми; 85 мм — крупные планы и предметы |
| Глубина | малая на 85 мм (фон читается пятнами), средняя на 35 мм |
| Высота камеры | уровень глаз; исключение — панель лифта и список снимаются фронтально |
| Движение | статика по умолчанию; медленный push-in не более 8 % кадра за 3 секунды |
| Handheld | только в панике, не дольше 2 секунд за серию |
| Запрещено | облёты, дроны, whip-pan, зум, любые «эффектные» движения |

**Язык камеры сериала (полный список разрешённых движений):**

1. `STATIC` — статика на штативе. Значение: дом наблюдает.
2. `SLOW PUSH-IN` — очень медленный наезд. Значение: герой принимает решение.
3. `SLOW PULL-OUT` — очень медленный отъезд. Значение: цена уже уплачена.
4. `PAN FOLLOW` — короткая проводка за движением. Значение: переход в другое пространство.
5. `POV` — от лица героя. Значение: только на пороге двери 46.
6. `LOW ANGLE` — снизу. Значение: дом сильнее человека.
7. `INSERT` — макро предмета. Значение: улика или цена.

## 5. Композиция

* Формат 9:16. Герой в нижней трети, воздух сверху под титры.
* Безопасные зоны: 12 % сверху, 20 % снизу — там UI площадок.
* Вертикали (косяк, лифт, стена) держат кадр; горизонт всегда ровный.
* Правило пустоты: в каждом кадре есть место, где **чего-то не хватает** — рифма к стиранию.
* Отражения (зеркало лифта, экран телефона, стекло списка) — фирменный приём.

## 6. Фактуры

Крашеный бетон, затёртый металл, поцарапанное зеркало, бумага под стеклом, пыль в луче,
дерматин двери, детская пижама с ворсом. Всё немного изношено, ничего не глянцевое.

## 7. Зерно и обработка

* Плёночное зерно 5–7 %, постоянное на весь сериал.
* Лёгкий halation на источниках света (кнопка 46, щель двери).
* Чёрное не проваливается в ноль: минимальный уровень тени `#0A0E14`.
* Никаких виньеток, глитчей, VHS-эффектов, хроматических аберраций.

## 8. Типографика

| Элемент | Правило |
|---|---|
| Шрифт | узкий гротеск, капслок, без засечек |
| Цвет | `#F2EDE4` на 90 % непрозрачности |
| Размер | высота строки 4,5 % кадра |
| Позиция | нижняя треть, над безопасной зоной |
| Объём | ≤ 12 слов, ≤ 2 строк, ≤ 42 знака в строке |
| Анимация | появление без эффектов, 3 кадра |
| Диегетический текст | список, экран телефона, табло — рисуется в кадре, не накладывается |

## 9. Звуковой образ

Пять маркеров сериала, узнаваемых без картинки:

1. Щелчок реле и низкий гул кнопки 46.
2. Открытие лифтовых дверей — сухой металл, без музыки.
3. Проворот замка двери 46 — медленный, на два оборота.
4. Домофонный щелчок перед голосом дома.
5. Шёпот дома — не слова, а воздух в шахте.

Музыка: один мотив в трёх состояниях (покой / решение / цена). Тишина — раз в серию.
