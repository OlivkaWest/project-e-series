# Seedance

**Роль в пайплайне:** image→video: короткие динамичные шоты, экшен

## Схема промпта

```
INPUT IMAGE: assets/keyframes/shNN.png
MOTION: одно движение субъекта
CAMERA: одно движение камеры
DURATION: N сек
NEGATIVE: ...
```

## Что работает

- движение из статичного кейфрейма при неизменной композиции;
- короткие шоты 1–3 сек под быстрый монтаж;
- динамика тела на среднем и общем плане.

## Что ломается

- два и более движения в одном промпте;
- крупные планы лица с движением камеры — лицо «плывёт»;
- смена костюма или фона в середине клипа.
