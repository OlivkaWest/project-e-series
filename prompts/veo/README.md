# Veo

**Роль в пайплайне:** кинематографичные планы, установочные кадры, шоты со звуком

## Схема промпта

```
SHOT: план, фокусное, движение камеры
SUBJECT: кто/что
ACTION: что происходит
SETTING: локация, время суток, погода
LIGHT: схема
AUDIO: диегетический звук сцены
STYLE: блок из bible/VISUAL_LANGUAGE.md
```

## Что работает

- общие и установочные планы, пейзаж, атмосфера;
- кадры с описанным движением камеры;
- генерация вместе с окружающим звуком.

## Что ломается

- длинные диалоги и точный липсинк;
- удержание персонажа без референса — только с identity-lock и кейфреймом;
- мелкий текст в кадре.
