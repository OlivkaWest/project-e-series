# ElevenLabs — голос

Один файл на реплику. Обязательные поля:

```text
CHARACTER:
TEXT:
EMOTION:
PACE:
PAUSES:
EMPHASIS:
VOICE ID:
MODEL:
STABILITY / SIMILARITY / STYLE:
LIPSYNC REQUIRED: yes/no
```

Правило проекта: диалог минимизируется там, где историю можно показать.
Уровень мастера речи: −16 LUFS, пики не выше −1 dBTP.
