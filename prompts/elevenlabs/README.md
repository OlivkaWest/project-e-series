# ElevenLabs

**Роль в пайплайне:** озвучка реплик, закадровый голос, дубляж

## Схема промпта

```
TEXT: реплика без служебных тегов
VOICE: voice_id
SETTINGS: stability / similarity / style / speed
```

## Что работает

- стабильный голос персонажа между эпизодами при фиксированном voice_id;
- пунктуация как инструмент ритма: точка = пауза, тире = задержка;
- дубляж на другой язык с сохранением тембра.

## Что ломается

- эмоции, вписанные в текст в скобках, — озвучиваются или ломают подачу;
- реплики длиннее 2–3 предложений в одном файле — интонация уплывает;
- ALL CAPS вместо режиссуры подачи.
