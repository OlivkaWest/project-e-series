# Промпты по инструментам

Одна папка = один генеративный инструмент. В каждой:

- `README.md` — что умеет модель, схема промпта, что ломается;
- шаблоны промптов;
- `LOG.md` — что реально сработало (промпт + seed + версия модели).

Порядок работы: собираем промпт из блоков `bible/VISUAL_LANGUAGE.md` +
`characters/*/identity-lock.md` + сцены, кладём в `PROMPTS.md` эпизода,
генерим через `pipeline/`, удачное — возвращаем сюда в `LOG.md`.

| Папка | Роль в пайплайне |
|-------|------------------|
| `nano-banana/` | изображения, кейфреймы, правки кадров |
| `seedance/` | image→video, короткие динамичные шоты |
| `grok/` | изображения, быстрые итерации, мемный/реалтайм-визуал |
| `kling/` | image→video, движение персонажа, длинные планы |
| `veo/` | text/image→video, кинематографичные планы со звуком |
| `elevenlabs/` | голос, дубляж |
| `heygen/` | говорящий аватар, липсинк |
