# HeyGen

**Роль в пайплайне:** говорящий аватар, липсинк под готовую дорожку

## Схема промпта

```
AVATAR: id аватара
AUDIO: assets/voice/....mp3
FRAMING: план
BACKGROUND: фон/сцена
```

## Что работает

- синхронизация губ под уже готовую озвучку из ElevenLabs;
- ведущий/рассказчик в кадре;
- повторяемое «лицо канала» между эпизодами.

## Что ломается

- сильные повороты головы и активная жестикуляция;
- сюжетные сцены с движением по локации;
- не использовать для главного героя, если он ведётся через identity-lock в image-моделях.
