# Kling

**Роль в пайплайне:** image→video: движение персонажа, диалоговые и длинные планы

## Схема промпта

```
INPUT IMAGE: assets/keyframes/shNN.png
MOTION: одно движение субъекта
CAMERA: static | push-in | pan
DURATION: 5s | 10s
NEGATIVE: morphing face, extra limbs, background warping
```

## Что работает

- удержание лица на среднем плане;
- плавное движение камеры без разрушения фона;
- сцены, где нужен более длинный непрерывный план.

## Что ломается

- быстрый экшен и резкая смена направления движения;
- руки крупным планом;
- несколько персонажей в кадре одновременно.
