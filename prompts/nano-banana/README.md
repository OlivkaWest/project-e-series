# Nano Banana

**Роль в пайплайне:** генерация и правка изображений: кейфреймы, референсы персонажей, локации

## Схема промпта

```
SUBJECT: кто/что
ACTION: одно действие
SETTING: локация + время суток
CAMERA: план, фокусное, ракурс
LIGHT: схема света
STYLE: блок из bible/VISUAL_LANGUAGE.md
NEGATIVE: ...
```

## Что работает

- редактирование готового кадра по текстовому описанию (правка детали без перегенерации всей сцены);
- сохранение персонажа при передаче референсных изображений;
- сборка кейфреймов, которые дальше уходят в video-модели.

## Что ломается

- длинные перечисления объектов в кадре — модель теряет часть;
- противоречивые указания по свету и времени суток;
- текст и надписи внутри кадра.
