# ElevenLabs — реплики

```text
CHARACTER:        имя из bible/NAMING.md
TEXT:             <= 8 слов
EMOTION:          состояние, не «страшно»
PACE:             медленный / обычный
PAUSES:           где и сколько
EMPHASIS:         какое слово
VOICE ID:         из .env, фиксирован на сезон
MODEL:            eleven_multilingual_v2
STABILITY / SIMILARITY / STYLE
LIPSYNC REQUIRED: yes / no
```

Нормы: речь −16 LUFS, пики ≤ −1 dBTP. Термины мира произносятся строго по словарю.
