# Grok / Grok Imagine

**Роль в пайплайне:** быстрые визуальные итерации, альтернативные варианты кадра, мемный и реалтайм-визуал

## Схема промпта

```
SUBJECT + ACTION + SETTING в одном абзаце естественным языком
STYLE: блок из bible/VISUAL_LANGUAGE.md
```

## Что работает

- быстрый перебор вариантов композиции до финальной генерации в основном инструменте;
- визуал под соцсетевой, «сырой» тон;
- работа с актуальным контекстом и трендами.

## Что ломается

- точная консистентность лица между генерациями;
- тонкий контроль света и оптики;
- не использовать как источник финальных кейфреймов без сверки с identity-lock.
