# Grok — текст, вариации, брейнштормы

Используется для: генерации вариантов хуков, заголовков, описаний, названий серий,
альтернативных финалов. Не используется для финального сценария — сценарий пишется
по `bible/STORY_RULES.md`.

Формат запроса: задача → ограничения → количество вариантов → критерий отбора.
