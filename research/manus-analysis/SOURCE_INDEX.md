## 5. Что в переданных материалах **отсутствует**

Это важно зафиксировать, чтобы не строить решение на несуществующих данных:

1. **Нет истории просмотров по дням** (SocialBlade/Studio). Все «скорости» — расчётные средние `просмотры / дни с публикации`.
2. **Нет данных о досмотрах и удержании (retention)** ни по одному ролику. Ни один вывод о «досматриваемости» не является измеренным.
3. **Нет данных о комментариях** в репрезентативном объёме — компонент Comment Demand не начислялся ни одному кейсу.
4. **Нет данных по TikTok, Reels и Telegram** — исследование покрывает только YouTube.
5. **Нет A/B-данных по хукам** — оценка силы хука экспертная, по наблюдению первых 1–3 секунд.
6. У 51 из 100 кейсов нет пары «просмотры + подписчики»; часть роликов на момент проверки была недоступна (`Video unavailable`).

> Вывод по источникам: материал пригоден для **выбора механики**, но не пригоден для прогноза абсолютных просмотров. Любой запуск обязан считаться экспериментом с собственным замером.
