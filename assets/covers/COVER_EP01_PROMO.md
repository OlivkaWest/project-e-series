# Обложка промо-Reels

## Решение

Хук — **невозможный факт**, по формуле из `.claude/skills/episode-cover`.
В кадре горит кнопка **46**. Текст говорит: **В ДОМЕ 9 ЭТАЖЕЙ**.
Свести одно с другим нельзя — на этом и держится.

Обложка не рассказывает, что ролик про Claude Code. Если написать про нейросети,
это станет постом про ИИ и потеряет хоррор. Технику зритель узнаёт из первой
фразы ролика — «Это не генерация. Это сериал», — и это работает как поворот.
Первый кадр ролика — та же панель, так что склейка обложка→видео непрерывна.

## Кадр

Панель лифта, восемь кнопок в латунных ободах, семь мёртвых. Пятая горит
приглушённым суриком, на ней цифра 46. Свечение уходит на три-четыре сантиметра
и гаснет. Нижняя треть — неосвещённая крашеная сталь, уходящая в чёрное.

Красный имеет физический источник — это лампа в кнопке. Правило соблюдено.

Референс материала: `LOC-01` панель, `c791a9f4`.

## Типографика

По `bible/TYPOGRAPHY.md` §3, Title:

| Параметр | Значение |
|---|---|
| Гарнитура | Oswald Light, вес 300 (`assets/fonts/Oswald.ttf`) |
| Регистр | ВЕРХНИЙ |
| Трекинг | +18 % |
| Цвет | `#E8E2D4`, непрозрачность 92 % |
| Кегль | подбирается так, чтобы «9 ЭТАЖЕЙ» занимало 76 % ширины — вышло 168 px |
| Позиция | нижняя треть, базовая линия блока на 88,5 % высоты |
| Тень, обводка | отсутствуют |

Две строки вместо одной: текст становится вдвое крупнее и читается на превью
размером с ноготь. `CLAUDE.md` разрешает до двух строк.

Тень запрещена, поэтому текст сажается не на эффект, а на реальную темноту:
низ кадра затемнён градиентом до `#0B0B0C` по степенному закону. Это грейд, а не
подложка под шрифт.

## Заголовок ролика

Формула «невозможный факт + личная ставка + номер серии»:

```
В нашем доме девять этажей. Ночью в лифте загорелась кнопка 46 | Серия 1
```

## Проверка по чек-листу навыка

- [x] читается на превью размером с ноготь — цифра и две строки
- [x] один вопрос, а не три
- [x] текст в две строки, три слова и число
- [x] красное имеет физический источник — лампа кнопки
- [x] невозможный факт в первых пяти словах заголовка
- [x] логотипа сериала нет
- [x] лица нет
