# Общие ассеты сериала

| Папка | Что лежит |
|---|---|
| `locations/` | Паспорта и референсы локаций: `LOCATION_BIBLE.md`, `MASTER_PROMPT.md`, `ANGLE_REFERENCES.md`, `LIGHTING.md`, `CONTINUITY.md` на каждую |
| `props/` | Ключевые предметы, которые обязаны совпадать между сериями |
| `textures/` | Фактуры: бетон, стекло, ткань, бумага |
| `logos/` | Логотип проекта, плашки, шрифтовые файлы |
| `music/` | Мотивы сериала: intro / tension / discovery / danger / cliffhanger |
| `sfx/` | Звуковые маркеры и эмбиенсы локаций |

Бинарные файлы крупнее 25 МБ в репозиторий не кладём — только ссылку и описание.
