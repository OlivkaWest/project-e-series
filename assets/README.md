# Ассеты сериала

Общие для всех эпизодов. То, что нужно только одному эпизоду, живёт в
`season-01/episode-XXX/assets/`.

| Папка | Что внутри | Именование |
|-------|-----------|------------|
| `locations/` | референсы локаций, по папке на локацию | `loc-01-<slug>/ref-*.png` |
| `props/` | реквизит и артефакты | `prp-01-<slug>/ref-*.png` |
| `textures/` | текстуры, оверлеи, зерно, блики | `<тип>-<slug>.png` |
| `logos/` | логотипы, плашки, эндкарты | `logo-<вариант>.png` |
| `music/` | сквозные темы сериала | `theme-<slug>-v01.wav` |
| `sfx/` | звуковая библиотека | `<категория>-<slug>.wav` |

Правила:
- ID локаций и реквизита совпадают с `bible/WORLD.md` §3 и §4;
- бинарники в git не коммитим (см. `.gitignore`), храним во внешнем хранилище,
  а в репозитории — только описание и ссылку;
- лицензии на всё стороннее фиксируем в `research/references.md`.
