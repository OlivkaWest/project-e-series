## 7. Сетевые ограничения этой сессии

Исходящий трафик идёт через политику egress. Заблокировано:

| Хост | Последствие |
|---|---|
| `d8j0ntlcm91z4.cloudfront.net` | **нельзя скачать сгенерированные изображения и видео в репозиторий** из этой сессии |

Обход политики не выполняется. Рабочая схема: результаты генерации смотрятся в галерее,
принятые кадры владелец кладёт в репозиторий вручную или через Google Drive.

## 9. Установка на macOS (для локальной машины владельца)

```bash
# базовые бинарники
brew install ffmpeg git-lfs jq
git lfs install

# python 3.11+
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# ключи
cp .env.example .env   # заполнить

# проверка
python3 pipeline/edit/validate_render.py --selftest
```
