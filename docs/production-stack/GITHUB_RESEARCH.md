# GITHUB RESEARCH — что рассмотрено и что берём

**Дата:** 21.08.2026 · **Метод:** поиск по GitHub и вебу + проверка доступных MCP-каталогов.

## OPTIONAL — пригодится позже, сейчас не ставим

| Инструмент | Когда понадобится | Почему не сейчас |
|---|---|---|
| **ComfyUI** (`comfyanonymous/ComfyUI`) | Если понадобится локальный контроль консистентности лиц через IP-Adapter / ControlNet | Тяжёлый локальный diffusion-стек, требует GPU. Наш pipeline построен на облачных API — пользы сейчас ноль |
| **whisperX** (`m-bain/whisperX`) | Диаризация нескольких говорящих | У нас ≤ 5 реплик на серию и говорящие известны заранее. `faster-whisper` достаточно |
| **auto-editor** (`WyattBlue/auto-editor`) | Автонарезка по тишине | Наш монтаж покадрово задан в `EDIT.md`. Автонарезка вредна |
| **Playwright** | Если сервис без API окажется критичным | Приоритет: официальный API → SDK → MCP → ручной экспорт → браузер. Пока не нужен |
| **YouTube Data API v3** | Аналитика канала после запуска | Нужен ключ; до публикации бесполезен |

## REJECTED — рассмотрено и отклонено, с причинами

| Что | Почему отклонено |
|---|---|
| **Каталоги «awesome-claude-code» / «awesome-agent-skills»** (VoltAgent, rohitg00, ComposioHQ, GetBindu) | Это витрины на сотни и тысячи чужих скиллов под универсальные задачи разработки. Ни один не решает задачу «производство вертикального сериала». Массовая установка чужих скиллов — прямой риск: непроверенный код и разрастание контекста. **Взяли идею формата, а не содержимое: агенты написаны под нашу библию.** |
| **Сторонние обёртки над ElevenLabs / Gemini** | Есть официальные SDK. Обёртка добавляет точку отказа и отстаёт от API |
| **`openai/whisper` оригинальный** | Медленнее `faster-whisper` в разы при том же качестве |
| **MoviePy** | Дублирует FFmpeg, но медленнее и капризнее на длинных цепочках. Один инструмент вместо двух |
| **Сторонние screenplay-фреймворки (Fountain, screenplain и подобные)** | Рассчитаны на полнометражный формат со сценами по страницам. У нас серия 35 секунд и покадровая сетка — формат из `bible/STORY_RULES.md` строже и точнее |
| **Пакет `srt`** | Не собирается в этой среде; формат SRT пишется в 15 строк без зависимости |
| **Docker-обвязка pipeline** | Усложняет без выгоды: весь стек — Python + FFmpeg |
| **Десяток дополнительных MCP** | Каждый MCP увеличивает поверхность риска и съедает контекст. Оставлены три реально нужных |
| **Прямая интеграция Runway** | Дублирует уже доступные через Higgsfield движки, требует отдельных платных credentials |
