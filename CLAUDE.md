# CLAUDE.md

Инструкции для агентов, работающих в этом репозитории.

## Что это за проект

Продакшн-система вертикального AI-сериала. Репозиторий хранит **текст и параметры**
(канон, сценарии, промпты, настройки генерации), а не медиа. Бинарники в git не попадают.

## Источники правды (в порядке приоритета)

1. `bible/SERIES_BIBLE.md` — формат, тон, каноны.
2. `bible/WORLD.md`, `bible/STORY_RULES.md`, `bible/VISUAL_LANGUAGE.md` — правила мира,
   драматургии и картинки.
3. `bible/CONTINUITY.md` — фактическое состояние после отрендеренных эпизодов.
4. `characters/*/identity-lock.md` — внешность персонажей.

Если задача противоречит этим файлам — сначала сказать об этом, потом делать.

## Жёсткие правила

- **Identity-lock копируется дословно.** Не перефразировать, не сокращать, не переставлять
  слова в блоке описания персонажа. Любая правка — только через `identity-lock.md`.
- **Стиль берётся из `bible/VISUAL_LANGUAGE.md`**, а не сочиняется в промпте заново.
- **Каждый промпт содержит seed и версию модели.** Без них результат неповторяем.
- **Одно движение на шот** (одно движение субъекта + одно камеры) — модели разваливают комбинации.
- **Шоты длиннее 10 секунд не генерируются** — собираются склейкой.
- **ID сквозные:** `sh01`, `LOC-01`, `PRP-01` одинаковы в шот-листе, промптах, монтаже и
  именах файлов.
- **После рендера обновляется `bible/CONTINUITY.md`.**

## Именование файлов

| Что | Шаблон | Пример |
|-----|--------|--------|
| Рендер шота | `ep<NNN>-<shot>-v<NN>.mp4` | `ep001-sh02-v03.mp4` |
| Кейфрейм | `<shot>-v<NN>.png` | `sh02-v01.png` |
| Озвучка | `ep<NNN>-<shot>-<персонаж>-v<NN>.mp3` | `ep001-sh02-mc-v01.mp3` |
| Мастер | `ep<NNN>.mp4` | `ep001.mp4` |

Версии не перезаписываются: новая попытка — новый номер.

## Формат PROMPTS.md

Промпты читаются скриптами, поэтому формат фиксирован: блок ```yaml с полями
`shot`, `tool`, `type`, `input_image`, `seed`, `duration`, `prompt`, `negative`.
Заголовки полей менять нельзя, добавлять новые — можно.

## Пайплайн

Все скрипты по умолчанию dry-run; `--execute` включает реальные вызовы API.
Никогда не запускать `--execute` без явной просьбы — это тратит кредиты.

```
generate_images.py → generate_video.py → generate_voice.py → assemble_episode.py → publish.py
```

Ключи только в `.env`, в код и в markdown не попадают.

## Стиль текстов

- Сценарии и документы — по-русски, термины продакшна можно оставлять английскими.
- В сценарии: реплики ≤ 12 слов, никакой экспозиции в диалоге, всё видимое — в ремарках.
- Не заполнять `TBD` выдуманными фактами без запроса: пустое поле честнее придуманного канона.
