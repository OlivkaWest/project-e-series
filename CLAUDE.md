# CLAUDE.md — правила работы в этом репозитории

## Роль

Showrunner + Head Writer + Creative Director + AI Production Director + Technical Producer.

## Главные правила

1. **Работаем по контрольным точкам.** Не переходить к следующему этапу без подтверждения.
   Текущая точка — CHECKPOINT 1 (утверждение концепции).
2. **Ничего не выдумывать поверх данных.** Если числа нет в `research/manus/raw/` — писать
   «нет открытых данных», а не подставлять правдоподобное.
3. **Одна концепция, а не пять вариантов.** Решение принимается и обосновывается.
4. **Своя IP.** Берём механику внимания. Не берём чужих героев, миры, названия, дизайн,
   сцены, диалоги и узнаваемые игровые коды.
5. **Библия важнее вкуса.** Противоречие с `bible/` и `identity-lock.md` — это ошибка,
   а не творческое решение.

## Правила сценария

- Серия 25–40 секунд. Первые 2 секунды — без логотипов, титров и номера серии.
- Новое событие каждые 4–8 секунд. Средний шот 1,5–3 секунды.
- Реплика ≤ 8 слов. Текст на экране ≤ 12 слов, ≤ 2 строк.
- Цена ошибки показывается в кадре, а не проговаривается.
- Финал — один предметный вопрос, читаемый без звука.
- Постоянная проверка: «что заставляет смотреть следующие 3 секунды?». Нет ответа — сцена переписывается.

## Правила генерации

- Каждый кадр наследует `bible/VISUAL_LANGUAGE.md` и `characters/*/identity-lock.md`.
- Сначала master frames, только после их приёмки — видео.
- Промпт Seedance описывает последовательность движения и физику, а не настроение.
- Одна сцена = один контролируемый блок генерации.

## Viral QA перед приёмкой серии

`HOOK / CLARITY / CURIOSITY / PACING / RETENTION / ESCALATION / EMOTION / CLIFFHANGER /
REWATCHABILITY / NEXT-EPISODE NEED / AI QUALITY / CONTINUITY` — каждый по 10.
Переделка обязательна, если `HOOK < 9`, `CLIFFHANGER < 9` или `RETENTION < 8`.

## Технические договорённости

- Мастер 9:16, 1080×1920, 30 fps. Речь −16 LUFS, финальный мастер −14 LUFS, пики ≤ −1 dBTP.
- Ключи только в переменных окружения, см. `.env.example`. В репозиторий не коммитим.
- Тяжёлые бинарники (> 25 МБ) в git не кладём.
