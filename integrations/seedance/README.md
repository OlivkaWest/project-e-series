# Seedance — `NOT_CONNECTED`

## Проверено 21.08.2026

В каталоге подключённого канала Higgsfield **видеомодели Seedance отсутствуют**.
Из ByteDance доступен только `seed_audio` (Seed Audio 1.0, синтез речи).

## Официальный путь

**Volcengine Ark.** Модели `doubao-seedance-2-0-260128` (стандарт)
и `doubao-seedance-2-0-fast-260128` (быстрее, ниже качество).

| Параметр | Значение |
|---|---|
| Частота кадров | **24 fps** |
| Соотношения | от 1:1 до 21:9 |
| Режимы | text-to-video, image-to-video, первый и последний кадр, мультимодальные референсы |
| Звук | нативная генерация — **у нас выключается** |
| Порядок цены | ~$0.93 за 5 секунд 1080p |

## Что нужно для подключения

Аккаунт Volcengine, доступ к Ark, `ARK_API_KEY` в `.env`.

## Важное предупреждение по непрерывности

Seedance отдаёт **24 fps**, мастер проекта — **30 fps**. Конверсия делается
фильтром `fps=30` в `pipeline/edit/assemble_episode.py`. Смешанный fps внутри
одной серии — технический брак, его ловит `video-qc`.

## Пока нет доступа

Формат промпта из `.claude/skills/video-production/` остаётся эталонным и
переносится на Cinema Studio 3.0 и Kling 3.0 без переписывания.
