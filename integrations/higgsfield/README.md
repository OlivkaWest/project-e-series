# Higgsfield — `CONNECTED`

Единственный **реально подключённый** генеративный канал. Авторизован через MCP.

| Что даёт | Модели |
|---|---|
| Изображения | `soul_2`, `soul_location`, `nano_banana_pro`, `grok_image` |
| Видео | `cinematic_studio_3_0`, `kling3_0`, `kling2_6`, `veo3`, `grok_video_v15`, `minimax_h3`, `flux_3_video`, `gemini_omni` |
| Аудио | `seed_audio` |
| Обработка | upscale, outpaint, reframe, remove background, motion control |
| Пакетно | `generate_image_batch`, `generate_video_batch` до 12 задач |

## Известное ограничение сессии

Домен выдачи `d8j0ntlcm91z4.cloudfront.net` закрыт политикой исходящего трафика
удалённой сессии: **скачать результат в репозиторий из сессии нельзя.**
Рабочая схема: результат смотрится в галерее, принятые файлы владелец кладёт
в репозиторий вручную или архивом. Политика не обходится.

## Правила вызова

* Соотношение сторон `9:16` всегда.
* `sound: off` для видео всегда.
* Seed принятого кадра записывается в журнал попыток и не меняется.
* Перед дорогой генерацией — `get_cost` для оценки.
